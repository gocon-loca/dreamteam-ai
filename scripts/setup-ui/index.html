DreamTeam Setup

Configure your autonomous coding system in a few steps.

Welcome to DreamTeam

An autonomous coding system you control on the go from your phone.

Describe what you want built in Telegram. AI agents work on your projects around the clock — writing code, running tests, reviewing their own work, and merging to main. You approve or reject from your phone.

What it does
  • Describe what you want built — from your laptop or phone
  • DreamTeam structures your ideas into goals for AI agents
  • Agents write code, run tests, and review their own work
  • 4-stage quality gates catch broken work before merge
  • Auto-merges, pushes, and notifies you on completion
  • Manages multiple projects in parallel, 24/7
How it works
  • Use Claude Code on your laptop, or Telegram on the go
  • A Director (AI) turns your ideas into structured goals
  • 3-tier model ladder (cheap → powerful) with auto-escalation
  • Supervisor dispatches goals to parallel workers
  • Code review, smoke tests, and merge gates
  • Morning digests, cost tracking, and analytics
Where to run it

DreamTeam is an always-on system — it keeps working while you're away. Choose where to host it based on your needs:

Your Laptop
Easiest way to try it out. Works great while your computer is on.
Keep-awake tip: On macOS, run caffeinate -s in a terminal to prevent sleep. On Linux, use systemd-inhibit. Close the lid and agents keep running.
Good for trying it out. Not ideal for overnight or multi-day runs.
Home Server / Mac Mini
Always on, no monthly fees. Use Tailscale to access from anywhere — your phone connects to the server over a private mesh network, no port forwarding needed.
Setup: Install Tailscale on both your server and phone. SSH in from anywhere. Telegram bot works globally via the internet — no tunneling required for that.
Recommended for individual developers. ~$600 one-time for a Mac Mini.
Cloud VPS
Run on a cloud server (Hetzner, DigitalOcean, AWS, etc). Most reliable uptime. Use Docker or install directly.
Requirements: 2+ CPU cores, 4GB+ RAM, Node 22, Git. A $20-40/mo VPS handles 3 concurrent workers easily.
Best for teams or always-on reliability. Dockerfile coming soon.

Jam.dev
What is Jam?

Jam.dev is a browser extension that captures bugs as shareable links — including console logs, network requests, screenshots, and video replay. When connected, DreamTeam agents can:

  • Read bug reports to understand what went wrong
  • Watch video replays of user-reported issues
  • Inspect console errors and failed network requests
  • Auto-create goals from Jam reports and fix bugs autonomously
Setup Steps
  1. Install the Jam browser extension
  2. Go to jam.dev/account/api and create an API key
  3. Paste the key below
Linear
What is Linear?

Linear is a project management tool with a kanban board. When connected, DreamTeam syncs goals bidirectionally:

  • Goals appear as Linear issues on your board
  • Status changes sync both ways (pending ↔ in progress ↔ done)
  • Track agent work alongside your human team's work
  • Use Linear's filters, labels, and views to manage goals
Setup Steps
  1. Go to linear.app/settings/api
  2. Create a Personal API key
  3. Paste the key below
